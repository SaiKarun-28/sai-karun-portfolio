# Sai Karun Portfolio Project

## What is this app?
A 5-portal interactive React + Vite TypeScript portfolio. A hero workspace photo with 7 hotspot buttons opens sections (GitHub, LinkedIn, Projects, Internships, Resume, Contact, Certifications).

## The angle
Deadpan / polished — the site is a serious portfolio with a slick interactive portal stage and a real architecture diagram.

## Key moments
- 7 hotspot cards over hero image.
- Projects (12 works), Internships (parsed from PDF), Resume, Certifications.
- Architecture diagram visual.

## Visual identity
- **Background:** dark (#0a0a0a) / gold (#cfa55b).
- **Font:** system sans.
- **Strongest visual:** hero workspace with portal cards.

## Technical Stack
- **Framework:** React + Vite.
- **Language:** TypeScript.
- **Deployment:** GitHub Pages via GitHub Actions.
- **Architecture:** SPA with absolute positioning for interactive portal hotspots.
